These are the original Inter (variable), Poppins (600/700), and JetBrains Mono (variable) WOFF2 assets previously downloaded by next/font/google for this portfolio. They were recovered from its existing static export, retaining the original unicode subsets, font weights, fallback metrics, and display behavior in app/fonts.css. Self-hosting avoids a Google Fonts network dependency during production builds.

Upstream projects and licenses:
